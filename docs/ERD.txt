ENTITY RELATIONSHIP DIAGRAM
============================

[USERS] (1) ────────────< (∞) [DIARY]
                                    users/{uid}/diary/{date}

[USERS] (1) ────────────< (∞) [POSTS]
                                    posts (uid field)

[POSTS] (1) ────────────< (∞) [COMMENTS]
                                    posts/{postId}/comments

[USERS] (1) ────────────< (∞) [HEALTH_DATA]
                                    users/{uid}/health_data/records

[USERS] (1) ────────────< (∞) [STEPS]
                                    steps

[USERS] <──followers/following──> [USERS] (Self-referencing)

[POSTS] <────────likes[]──────── [USERS] (Many-to-Many via array)


ENTITIES & ATTRIBUTES
=====================

1. USERS
   - uid (PK)
   - username
   - email
   - photoUrl
   - bio
   - sex
   - isDarkMode
   - bookmarkedRecipes[]
   - followers[] → USERS
   - following[] → USERS

2. DIARY (Subcollection of USERS)
   - date (PK: d-M-y)
   - totalCalories
   - totalProtein
   - totalCarbs
   - totalFat
   - water
   - weight[]: {hour, minute, weight, bodyFat, notes}
   - breakfast: {calories, protein, fat, carbs, foods[]}
   - lunch: {calories, protein, fat, carbs, foods[]}
   - dinner: {calories, protein, fat, carbs, foods[]}
   - snack: {calories, protein, fat, carbs, foods[]}

3. POSTS
   - postId (PK)
   - uid → USERS
   - username
   - description
   - likes[] → USERS
   - postUrl
   - profImage
   - datePublished

4. COMMENTS (Subcollection of POSTS)
   - commentId (PK)
   - uid → USERS
   - name
   - profilePic
   - text
   - datePublished

5. HEALTH_DATA / RECORDS (Subcollection of USERS)
   - recordId (PK)
   - Heart rate / BPM data
   - Timestamp

6. STEPS (Root Collection)
   - Step count data per user
   - Date-based records


RELATIONSHIPS
==============

| From      | To         | Type        | Implementation    |
|-----------|------------|-------------|-------------------|
| USERS     | DIARY      | 1 : ∞       | Subcollection     |
| USERS     | POSTS      | 1 : ∞       | Root + uid field  |
| POSTS     | COMMENTS   | 1 : ∞       | Subcollection     |
| USERS     | HEALTH_DATA| 1 : ∞       | Subcollection     |
| USERS     | STEPS      | 1 : ∞       | Root collection   |
| USERS     | USERS      | ∞ : ∞       | followers[] array |
| POSTS     | USERS      | ∞ : ∞       | likes[] array     |
