╔═══════════════════════════════════════════════════════════════════════════════════╗
║  CARDINALITY NOTATION:                                                         ║
║    (1:N) = One to Many    │    (N:1) = Many to One    │    (N:N) = Many to Many  ║
║    EMBED = Dữ liệu lồng nhau trong document                                     ║
╚═══════════════════════════════════════════════════════════════════════════════════╝

  USERS ───────────────────────────────────────────────────────────────────────────────
   │
   ├─► (1:N) ── MEALS ──► (EMBED) FOODS      : User ghi nhận bữa ăn chứa foods
   │
   ├─► (1:N) ── WATER_INTAKES                : User ghi nhận lần uống nước
   │
   ├─► (1:N) ── WEIGHTS                     : User ghi nhận cân nặng
   │
   ├─► (1:N) ── SLEEPS                      : User ghi nhận giấc ngủ
   │
   ├─► (1:N) ── HEART_RATES                 : User đo nhịp tim
   │
