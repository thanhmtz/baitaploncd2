================================================================================
                         1. COLLECTION: USERS
================================================================================

┌─────────────────────────────────────────────────────────────────────────────┐
│ Tên field          │ Kiểu dữ liệu   │ Mô tả                               │
├─────────────────────┼─────────────────┼─────────────────────────────────────┤
│ uid                │ String          │ ID người dùng (Primary Key)        │
│ email              │ String          │ Email đăng nhập                     │
│ username           │ String          │ Tên người dùng                      │
│ photoUrl           │ String          │ URL ảnh đại diện                    │
│ bio                │ String          │ Tiểu sử                             │
│ sex                │ Integer         │ Giới tính (1=Nam, 2=Nữ)            │
│ isDarkMode         │ Boolean         │ Chế độ tối/sáng                     │
│ bookmarkedRecipes  │ List<String>    │ Danh sách recipe yêu thích          │
│ followers          │ List<String>    │ Danh sách người theo dõi            │
│ following          │ List<String>    │ Danh sách người đang theo          │
│ created_at         │ Timestamp       │ Ngày tạo tài khoản                  │
└─────────────────────────────────────────────────────────────────────────────┘

Ví dụ:
{
  "uid": "abc123xyz",
  "email": "user@example.com",
  "username": "John Doe",
  "photoUrl": "https://...",
  "bio": "Yêu thích tập thể dục",
  "sex": 1,
  "isDarkMode": false,
  "bookmarkedRecipes": ["recipe1", "recipe2"],
  "followers": ["user1", "user2"],
  "following": ["user3"],
  "created_at": "2024-01-01T00:00:00Z"
}
